# STMS Updates

## 10.11.2026 Update

### Changelog

#### Supervisor's Card

It is not possible to enter a grade for a future date. The test date cannot be set later than today.

#### Subject Settings

In the subject settings, the Transcript Name field has the correct label (previously, it was called Diploma Level).

### WIP Bible module

The new Bible Verses module will be much more convenient for teachers than the previous version.

Previously, teachers had to assign Bible passages themselves. Now, the passage text and expected completion date will be entered by an administrator.

As before, teachers will need to specify the date when the student is expected to recite the Bible passage in a dedicated tab.

The module will be integrated with HR completion tracking. If no completion date is specified for a Bible passage, the HR status cannot be changed to Completed.

Students will be able to see the required Bible passages in their personal accounts.

A new widget will also be added to the Supervisor Dashboard, displaying students who have not yet completed their Bible passage assignment.

### WIP Chat
Of course, work on the chat is also underway.

Basic Markdown formatting is already supported. Users can either type Markdown syntax directly or use the formatting toolbar. Currently, the toolbar supports bold, italic, bulleted lists, and hyperlinks.

The first chat update will focus on groups. Just like in the messaging apps we are familiar with, users will be able to create groups and communicate in a many-to-many format.
